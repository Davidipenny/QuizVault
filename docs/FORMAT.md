# 题库格式规范

本文档定义了 QuizVault 的题库数据格式，包括 v2 统一 JSON、Markdown 导入格式，以及 `banks/` 目录使用的旧版兼容交换格式。

v2.0 运行时使用 SQLite。启动时会只读识别随程序提供或同级旧项目中的 `banks`，并自动、幂等地导入；以下是导入与交换格式，不再是运行时事实来源。新导入建议使用下述统一 JSON 格式。

## 0. v2.0 统一题目 JSON

```json
{
  "type": "single",
  "prompt": "题干",
  "case_material": "可选案例材料",
  "choices": [
    {"label": "A", "content": "选项一"},
    {"label": "B", "content": "选项二"}
  ],
  "answer_spec": {"correct": ["A"]},
  "explanation": "解析",
  "source": "来源"
}
```

`answer_spec` 按题型定义：

| type | answer_spec | 判分规则 |
|------|-------------|----------|
| `single` | `{"correct":["A"]}` | 唯一选项一致 |
| `multi` | `{"correct":["A","C"]}` | 至少两个答案，集合完全一致 |
| `any` | `{"correct":["A"]}` | 一个或多个答案，集合完全一致 |
| `truefalse` | `{"value":true}` | 布尔值一致 |
| `fill` | `{"blanks":[["答案","别名"]],"unordered":false}` | 每空匹配任一可接受答案 |
| `essay` | `{"reference":"参考答案"}` | 默认用户自评，可选规范化文本比对 |

文本规范化只处理首尾空白、全角空格和换行，不忽略标点，也不进行语义判分。同一题库按“题型 + 规范化题干 + 规范化选项”的 SHA-256 指纹去重。

刷题会话的公开题目响应与编辑/导入格式不同：普通模式不返回 `answer_spec` 或选项 `is_correct`，填空题通过 `answer_meta.blank_count` 和 `answer_meta.unordered` 描述输入结构。提交答案后才返回参考答案与解析；背题模式会返回答案数据供用户点击“查看答案”后展示。

## 1. Markdown 导入格式

### 1.1 章节标题区分默认题型

在 Markdown 文件中使用 `##` 标题来设置后续题目的默认题型：

```markdown
## 判断题
（后续题目默认为 truefalse）

## 单选题
（后续题目默认为 single）

## 多选题
（后续题目默认为 multi）
```

标题匹配规则（宽松匹配，不区分大小写）：
- 标题文本中包含"判断"或"truefalse" -- 默认题型设为 `truefalse`
- 标题文本中包含"单选"或"single" -- 默认题型设为 `single`
- 标题文本中包含"多选"或"multiple" -- 默认题型设为 `multi`

### 1.2 单题类型覆盖

如果某道题的题型与当前章节默认类型不同，可在题目上方添加 HTML 注释覆盖：

```markdown
<!-- multi -->
**5. 这道题在单选题章节里，但实际是多选**
A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案：ABC**

**解析：** ...
```

支持的注释：
- `<!-- truefalse -->` -- 强制后续题目为判断
- `<!-- single -->` -- 强制后续题目为单选
- `<!-- multi -->` -- 强制后续题目为多选

注释一旦出现会持续生效，直到下一个章节标题或另一条类型注释，而非只影响紧跟其后的一道题。此外，由标题或注释显式指定的单选/多选类型不会因答案字母数量被自动纠正（见 1.3）。

### 1.3 题目格式

每道题由以下部分组成，各部分之间用空行分隔：

```markdown
**1. 题目文本（　）**
A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案：A**

**解析：** 解析内容

---
```

各元素说明：

| 元素 | 格式 | 说明 |
|------|------|------|
| 题号 | `**数字.**` | 必须是数字后跟句点，用 `**` 粗体包裹 |
| 题干 | `**题号. 题干文本（　）**` | 包含在粗体标记内；必须含有全角括号 `（　）`，否则整道题不会被解析 |
| 选项 | `A. 文本` | 每行一个，以大写字母 A-D 加句点开头 |
| 答案 | `**答案：X**` | 粗体包裹，冒号后为 A-D 内的答案字母 |
| 解析 | `**解析：**` | 粗体标记"解析："后跟解析文本 |
| 分隔线 | `---` | 可选，用于分隔各题 |

题型自动纠正：单选题的答案含多个字母时自动按多选题处理；多选题（仅由"一、单项选择题"这类章节标记推断、未经标题或注释显式指定）的答案只有一个字母时自动回退为单选题。

### 1.4 完整示例

````markdown
## 判断题

**1. 实践是检验真理的唯一标准（　）**
A. 正确
B. 错误

**答案：A**

**解析：** 这是马克思主义认识论的基本观点。

---

## 单选题

**1. 毛泽东思想形成和发展的时代条件是（　）**
A. 俄国十月革命开辟了世界无产阶级社会主义革命的新时代
B. 1840年以后中国人民面临的反帝反封建任务
C. 五四运动开辟了世界无产阶级社会主义革命的新时代
D. 中国革命和建设的丰富实践

**答案：A**

**解析：** 毛泽东思想形成于20世纪前中期，当时的时代条件是俄国十月革命的胜利开辟了世界无产阶级社会主义革命的新时代。

---

<!-- multi -->
**2. 实际上是多选题（　）**
A. 马克思列宁主义在中国的运用和发展
B. 被实践证明了的关于中国革命和建设的正确的理论原则和经验总结
C. 中国共产党集体智慧的结晶
D. 毛泽东个人的思想

**答案：ABC**

**解析：** 毛泽东思想不等于毛泽东个人的思想，它是党和人民集体智慧的结晶。

---

## 多选题

**1. 毛泽东思想的活的灵魂包括（　）**
A. 实事求是
B. 群众路线
C. 独立自主
D. 与时俱进

**答案：ABC**

**解析：** 毛泽东思想的活的灵魂包括实事求是、群众路线、独立自主三个方面。

---
````

## 2. `banks/` 目录交换格式（旧版兼容）

自动导入扫描 `banks/<题库名>/` 下的 `questions.md`（上节格式）和 `*.json`。JSON 文件使用旧版兼容结构，同时携带 v2 的 `answer_spec`：

```json
{
  "questions": [
    {
      "id": 1,
      "type": "single",
      "question": "毛泽东思想形成和发展的实践基础是（　）",
      "options": {"A": "中国工人运动的发展", "B": "马克思列宁主义在中国的传播", "C": "中国共产党领导人民进行革命", "D": "中国革命和建设的丰富实践"},
      "answer_spec": {"correct": ["C"]},
      "answer": "C",
      "explanation": "解析内容"
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `id` / `type` / `question` / `options` / `answer` | 旧版 v1 字段；`options` 为字典，`answer` 为字母串 |
| `answer_spec` | v2 答案结构，与第 0 节一致；缺失时由 `answer` 推导 |
| `explanation` | 解析，可省略 |

导入时同样执行第 0 节的校验与 SHA-256 指纹去重，重复内容按 `legacy_mappings` 幂等跳过。可用 `scripts/export_banks.py` 从 SQLite 导出此格式。

> 历史说明：v1 曾使用 `questions.yaml` 存储（含 `meta` 统计块、`content_hash`（MD5 前缀）与 `flagged` 字段），并由独立的 `import_questions.py` 校验。该工具链已随 v2 移除，此处仅作记录；请勿按其编写新数据。

## 3. AI 生成题目模板

将以下提示词粘贴给 AI，可生成符合导入格式的题目：

````markdown
请按以下 Markdown 格式生成选择题：

## 判断题

**1. 题目文本（　）**
A. 正确
B. 错误

**答案：A**

**解析：** 解析内容

---

## 单选题

**1. 题目文本（　）**
A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案：A**

**解析：** 解析内容

---

## 多选题

**1. 题目文本（　）**
A. 选项A
B. 选项B
C. 选项C
D. 选项D

**答案：ABC**

**解析：** 解析内容

---

要求：
1. 判断题答案为 A 或 B，选项为"正确/错误"
2. 单选题答案为 A-D 中的一个字母
3. 多选题答案为 2-4 个不重复的 A-D 字母
4. 判断题必须有 2 个选项，单选/多选题必须有 4 个选项
5. 解析要说明正确答案的原因和其他选项的错误
6. 题号按顺序编号
7. 用 --- 分隔每道题
````
